What this simulator represents

All five true UAV paths use certified segments across the Phase 1 polygon, with at least 18 m horizontal clearance. Zigzag uses straight legs with sharp waypoint turns. The displayed reflex included angle is 180° plus the absolute heading change (maximum 330°); it is not a commanded 330° yaw maneuver. Altitude controls use the same flat datum; no vertical geofence or aircraft dynamics are modeled. Tracking estimates remain unconstrained so estimation errors remain visible.

These are synthetic measurement-level results. No field IQ, site calibration, ray tracing, detection processor, NR conformance, or hardware validation is included.

Cooperative uplink SRS

The UAV sends SRS. Each array observes noisy one-way range, azimuth, elevation and radial velocity. Absolute range assumes calibrated UAV timing. Clock uncertainty is independent jitter, not an estimated shared clock state.

Downlink PRS / DMRS / SSB

Choose same-site monostatic echoes, ordered inter-site bistatic links, or both. Monostatic operation requires an echo-capable receiver and transmit leakage isolation. Bistatic path length and path rate are fused with receive angles. This requires echo-capable receivers, synchronized sites, a direct-path reference and clutter cancellation. It does not assume that a standard O-RU already provides radar data.

Tracking and resources

A six-state constant-velocity EKF uses scalar sequential updates with numerical Jacobians and a 5σ innovation gate after acquisition. Selected half-wavelength array dimensions enter through an angle-noise proxy; ideal gain and carrier scaling follow the chosen normalization. Reference profiles now determine pilot count, occupied bandwidth and observation cadence. SSB bandwidth is capped at 240 times selected SCS. A normalized information proxy couples sensing reservation to measurement noise; it is not a waveform-derived bound.

Reproducibility

Seeded noise, exact source engine and exported configuration permit replay. Fused mode combines SRS + PRS under the selected reservation; resource admission is statistical, not a full NR scheduler. The UE rate model uses normalized SINR, ideal MIMO rank and an implementation-efficiency factor. Ground plane is flat and heights share a local datum. Parameters need not form a standards-valid NR schedule.

3GPP TS 38.211 via ETSI defines the reference signals; this app does not implement their resource grids.
